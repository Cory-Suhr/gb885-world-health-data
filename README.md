# World Health Data Analysis

## Project Overview
This project analyzes global health data using Python and pandas. The notebook explores relationships between health, economic, and demographic indicators across countries.

## Business Question
The goal of this analysis is to better understand how factors such as health care spending, infant mortality, maternal mortality, life expectancy, and economic conditions are related. The notebook answers several analytical questions about world health statistics.

## Data Source
The data comes from the World Health dataset that was provided for Assignment 4 in the GBB885 course.

## Tools Used
- Python
- Pandas
- Google Colab / Jupyter Notebook

## How to Run
1. Download or clone this repository.
2. Open the notebook (`GB885_Assignment_4_Suhr_C.ipynb`) in Google Colab or Jupyter Notebook.
3. Make sure the dataset is available in the same location as the notebook.
4. Run all cells from top to bottom.
